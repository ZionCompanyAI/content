## 🏭 A fábrica autônoma de software

No centro do nosso método está o **Mission Control** — um orquestrador onde agentes de IA especializados colaboram entre si para entregar software de ponta a ponta:

- **Agentes especializados** — arquitetura, desenvolvimento, revisão de código e operações, cada um com um papel claro.
- **Comunicação agente-a-agente (A2A)** — os agentes conversam, delegam tarefas e debatem decisões técnicas em tempo real, com barramento durável (nenhuma mensagem se perde).
- **Pipeline da issue ao merge** — agentes escrevem código orientado por especificação e por *testes-oráculo*, rodam o gate de qualidade (lint + testes) antes de abrir PR, e integram com revisão — humano aprovando o que importa.
- **Auto-cura e observabilidade** — sensores detectam degradação (filas travadas, serviços instáveis) e disparam correção antes do impacto.
- **Memória durável** — cada agente preserva contexto e lições aprendidas; conhecimento é versionado, não esquecido.

> O princípio: **autonomia onde é seguro, humano onde é decisivo.** A engenharia decide o técnico; o negócio decide o negócio.

## 🛠️ Como trabalhamos (princípios de engenharia)

- **Spec-Driven Development** — toda mudança nasce de uma especificação com critérios verificáveis.
- **Teste como oráculo** — correções acompanham um teste que reproduz a condição real antes de corrigir.
- **Shift-left de qualidade** — o gate (lint + testes) roda antes do PR, não depois.
- **Decisões registradas (ADRs)** — escolhas de arquitetura são documentadas e rastreáveis.
- **Conventional Commits + SemVer** — histórico legível, releases previsíveis.
- **Rastreabilidade total** — toda mudança em produção gera registro.
