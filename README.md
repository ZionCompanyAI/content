## 🏭 A fábrica (o núcleo)

**ZionCompanyAI é a fábrica de software agêntica** do Grupo MBZSoluções — o motor que projeta, constrói e opera software com agentes de IA especializados. No coração dela está o **Mission Control**, onde os agentes colaboram de ponta a ponta:

- **Agentes especializados** — arquitetura, desenvolvimento, revisão de código e operações, cada um com papel claro.
- **Comunicação agente-a-agente (A2A)** — os agentes conversam, delegam e debatem decisões técnicas em tempo real, com barramento durável (nenhuma mensagem se perde).
- **Pipeline da issue ao merge** — código orientado por especificação e por *testes-oráculo*, gate de qualidade (lint + testes) antes do PR, integração com revisão — humano aprovando o que importa.
- **Auto-cura e observabilidade** — sensores detectam degradação e disparam correção antes do impacto.
- **Memória durável** — cada agente preserva contexto e lições; conhecimento é versionado, não esquecido.

> O princípio: **autonomia onde é seguro, humano onde é decisivo.** A engenharia decide o técnico; o negócio decide o negócio.

## 🛠️ Como trabalhamos (princípios de engenharia)

- **Spec-Driven Development** — toda mudança nasce de uma especificação com critérios verificáveis.
- **Teste como oráculo** — correções acompanham um teste que reproduz a condição real antes de corrigir.
- **Shift-left de qualidade** — o gate (lint + testes) roda antes do PR, não depois.
- **Decisões registradas (ADRs)** — escolhas de arquitetura são documentadas e rastreáveis.
- **Conventional Commits + SemVer** — histórico legível, releases previsíveis.
- **Rastreabilidade total** — toda mudança em produção gera registro.
